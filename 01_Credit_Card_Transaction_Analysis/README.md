# Credit Card Transaction Analysis

## Business Problem

A bank observed that credit card transaction volume declined from June to July 2026.

The objective of this project was to identify possible reasons behind the decline using SQL and provide business recommendations.

---

## Dataset

This project uses three tables:

- Customers
- Merchants
- Transactions

---

## Skills Demonstrated

- SQL
- JOINs
- GROUP BY
- CASE WHEN
- Aggregations
- Correlated Subqueries
- NOT EXISTS
- Root Cause Analysis
- Business Intelligence
- Data Analytics

---

## Business Questions Answered

1. Did overall transactions decline?
2. Which merchant categories changed?
3. Which states showed lower activity?
4. Which customer age groups were affected?
5. Did gender influence the decline?
6. Which income segments changed?
7. Was a specific card type responsible?
8. Were transactions being declined?
9. Which customers became inactive?

---

## Key Findings

- Overall transactions declined from June to July.
- Credit card usage decreased.
- Travel and Shopping activity declined.
- Washington experienced lower transaction activity.
- No increase in declined transactions was observed.
- One customer became inactive during July.

---

## Business Recommendations

- Increase credit card engagement campaigns.
- Investigate reduced spending in Travel and Shopping.
- Analyze customer behavior in Washington.
- Re-engage inactive customers.
- Continue monitoring monthly transaction trends.
